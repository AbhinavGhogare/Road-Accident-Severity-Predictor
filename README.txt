MODEL
-----

150 estimators
max_depth = 10
random_state = 42
One-Hot Encoding
Input features = 9
Target = Severity

RUN THE PYTHON PREDICTOR
------------------------
Open PowerShell in this folder:

    pip install -r requirements.txt
    python road_accident_Severity_predictor.py

This creates/updates confusion_matrix.png and prints evaluation + sample prediction.

RUN THE WEB DASHBOARD
---------------------
1. Open the frontend folder:

    cd frontend

2. Install dependencies:

    pip install -r requirements.txt

3. Start:

    python app.py

4. Open:

    http://127.0.0.1:5000

The dashboard uses ../road_accident_data.csv so it works with the same packaged dataset.

DEMO FLOW FOR MAM
-----------------
1. Start the web dashboard.
2. Show Dashboard Overview.
3. Open Prediction.
4. Click "Load Demo Case".
5. Click "Predict Severity".
6. Show the predicted class and probability bars.
7. Open Analytics.
8. Open About Model.
9. Finally show confusion_matrix.png and the project report.
